# THE 24 — V2

Second version of The Twenty Four marketing site. Editorial / magazine-grid aesthetic, pure black on white, Instrument Serif + Hubot Sans.

## Stack
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS 3.4
- Framer Motion 11
- Deployed to Vercel (region: sfo1)

## Local dev
```bash
npm install
npm run dev
```

## Structure
- `/` — finished homepage
- `/availability`, `/amenities`, `/neighborhood`, `/campus`, `/gallery`, `/community`, `/contact` — stubbed using `PageShell`

## Design tokens
- `ink` `#030003` — primary text + dark panels
- `paper` `#FFFFFF` — default background
- `bone` `#F2F2F2` — split section background
- `font-display` — Instrument Serif (editorial display)
- `font-sans` — Hubot Sans / Inter fallback (UI)
